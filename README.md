# 3D maze using raycasting

## Installation

1. Clone repository
2. open repository on IDE
3. Creat virtual environment: `python -m venv .venv`
4. Activate it `source .venv/Scripts/activate`
5. Install dependencies `pip install -r requirements.txt`
6. Run `python main.py`

## The design 
![Design CLaude and I settled on](assets/system_design.png)

### Algorithms
- Raycasting to turn a 2D environment into a 3D (or more of a 2.5D) visual
- Digital Differential Analyzer (DDA) to optimize the raycasting by interpolating rays' variables, reducing computation
